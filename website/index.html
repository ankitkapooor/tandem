Not sure which Mac? Open Apple menu → About This Mac. “Chip” means Apple Silicon; “Processor: Intel” means Intel.

OR INSTALL FROM TERMINAL
curl -fsSL https://raw.githubusercontent.com/ankitkapooor/tandem/main/install.sh | bash

Downloads the latest Mac app to Applications.

  1. 1

    Give your agents a home.

    Install Claude Code and Codex CLI, then sign in from Terminal. Both are needed for two-agent workflows; one is enough for Solo.

    claude then /logincodex login

    Uses your existing subscriptions and their usage limits. No separate tandem account or API key.

  2. 2

    Download. Drag. Open.

    Open the DMG and drag tandem to Applications. The app is currently unsigned: right-click it and choose Open on the first launch, then confirm if macOS asks.

    The Terminal installer handles installation too. No Node or npm needed for the Mac download.

  3. 3

    Check the dots. Start a thread.

    Open Settings and check that your installed agents show green status dots. Type a question, choose a mode, and review the plan before you send.

    Updates are offered in the app. Your threads and notes stay in ~/.tandem.

Add tandem to your iPhone ＋
  1. In tandem on the Mac, open Settings and turn on Phone access.
  2. Scan the QR code with your iPhone and open the link in Safari.
  3. Tap Share → Add to Home Screen, then launch tandem from the new icon.

Keep the Mac awake and on the same Wi-Fi. For access away from home, use Tailscale. The QR link contains a secret token: anyone with it can use your connected agents while Phone access is on. Turn it off when you’re done.

Do I need both subscriptions?＋

Use at least one installed and signed-in CLI with access to its provider. Solo works with one agent. Relay, Parallel, and Debate need both. tandem uses those tools’ existing authentication and usage limits; it does not include a model subscription.

Is this page the app?＋

This is the download and setup page. The actual application runs on your Mac, and optional iPhone access connects to that Mac. There is no hosted chat app on this domain.

What should I know before installing?＋

The Mac app is currently unsigned. Replies appear when each agent’s step finishes, rather than streaming word by word. Codex may not see attached images in resumed conversations, though it receives their file paths. Windows and Linux are not packaged yet.

My agent says “not logged in” or “CLI not found.”＋

Install the missing CLI and sign in in Terminal: run claude and then /login, or run codex login. Restart tandem afterward. Login slash commands belong in the CLI, not in tandem’s conversation.

How do updates work?＋

tandem checks GitHub for updates when it opens and every six hours. When an update is available, you can choose Update now or Later. You can also select Check for Updates in the tandem menu. Threads and notes are kept.
